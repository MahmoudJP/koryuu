# Project Instructions

## Project

Koryuu is a public website that presents Mahmoud's applications and projects.
It uses Next.js static export and deploys to Cloudflare Pages.

## Commands

```bash
npm ci
npm run dev
npm run lint
npm run build
```

## Rules

- Keep the website compatible with Windows and macOS development.
- Do not commit `.env.local`, `.wrangler`, dependencies, or build output.
- Do not deploy to Cloudflare without explicit approval.
- Run lint and build before proposing a push.
- Keep `docs/STATUS.md` updated when the project state changes.
- Explain user-facing changes in simple language.
- Never expose API keys, tokens, analytics secrets, or private user data.
